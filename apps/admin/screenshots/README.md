# Screenshots للتطبيق (PWA)

هذه الصور تُستخدم في manifest.json لوصف التطبيق عند التثبيت.

## المطلوب:
- `screenshot-1.png` — 1080×1920 (رأسية) — الصفحة الرئيسية
- `screenshot-2.png` — 1080×1920 (رأسية) — المتاجر
- `screenshot-3.png` — 1080×1920 (رأسية) — لوحة تحكم

## كيف تُنتجها:
1. افتح التطبيق على الهاتف
2. **Screenshot** للشاشات المطلوبة
3. انسخها هنا

**مؤقتًا:** التطبيق يعمل بدونها.
